# Documentation site

The OpenBox documentation site is a separate repository: `openboxgl.github.io` (Next.js static export, deployed to GitHub Pages at https://openboxgl.github.io).

The directories under this `docs/` folder are empty scaffolding left over from the old Astro-based site. All current documentation content lives in the `openboxgl.github.io` repo under `content/docs/`, with the marketing home page in `app/page.tsx` and its section components in `components/`.

Do not add markdown here. Edit the docs site repo instead.
