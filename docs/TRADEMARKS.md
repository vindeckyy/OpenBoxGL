# Trademark and branding policy

OpenBox Game Launcher is an independent open-source Linux game library manager and launcher.

## Project identity

Use the full name **OpenBox Game Launcher** on first mention in public listings, package descriptions, screenshots, release announcements, and AppStream metadata. Short name **OpenBox** may be used after first mention. The project is unrelated to [Openbox](https://openbox.org/), the Linux window manager, and is not affiliated with its maintainers.

The project is also independent from LaunchBox, Big Box, Unbroken Software, LLC, and every other third-party product named in the repository. Do not describe OpenBox Game Launcher as official, endorsed, sponsored, or produced by another project or company. Do not use composite names that suggest affiliation, such as OpenBox LaunchBox, OpenBox for LaunchBox, or LaunchBox on Linux by OpenBox.

The `io.openbox.GameLauncher` application ID and `openbox://` URI scheme are technical identifiers under the FreeDesktop reverse DNS convention. They do not imply affiliation with the Openbox window manager and must not be presented as an endorsement.

## Nominative fair use

Third-party names, logos, and marks belong to their respective owners. OpenBox uses product names in documentation and interface text only when needed to describe:

- compatibility or interoperability;
- supported import, launch, or metadata workflows; or
- a factual feature comparison against a named product on a named platform.

When a third-party name appears, use it in plain text with correct capitalization and without altering its logo or trade dress. Do not place a third-party logo next to the OpenBox logo in a way that implies co-branding. When space allows, include the attribution line from [DISCLAIMER.md](DISCLAIMER.md) that marks are property of their owners.

## Third-party assets

Do not copy third-party logos, artwork, cover art, screenshots, or other branded assets into the repository, release artifacts, or documentation site without a documented license or written permission. Showcase images are user supplied captures of user supplied games and follow the same rule. New contributions that include third-party assets must state the source, the applicable license, and that the contributor has the right to submit them. See [DISCLAIMER.md](DISCLAIMER.md) section 3 and the Developer Certificate of Origin in [CONTRIBUTING.md](CONTRIBUTING.md).

## Formal notices

Do not post private contact details or formal legal notices in public issues, discussions, or pull requests. Use GitHub's [copyright claims form](https://github.com/contact/dmca) for copyright complaints and the [GitHub Trademark Policy](https://docs.github.com/en/site-policy/content-removal-policies/github-trademark-policy) for trademark complaints. GitHub is the designated agent for content hosted on GitHub. The project cannot determine the legal validity of a complaint. Formal notices should use the applicable GitHub process or qualified legal counsel.

This policy is a project guideline, not legal advice. It does not determine whether a particular use is lawful in any jurisdiction. Consult qualified counsel for jurisdiction-specific questions.
