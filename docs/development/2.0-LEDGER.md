## Cross-cutting decisions

- **2.0.0 version bump (plan 16.3).** The tree stays at 1.19.1 until the release commit:
  `updates.py` declares 1.19.1 and `scripts/check_version_sync.py` passes. The bump happens
  in the release commit (W8-06 and W8-07) together with the AppStream release entry, so the
  updater never offers a version that was never published.
- **Definition of done (plan section 21).** Re-audited on 2026-10-29 with
  `scripts/check_tests.py`: 243 test files pass, total coverage 85.0% (floor 85), web_app 73.0%
  (floor 62), new runtime modules at or above 88%, every ratchet gate green. The ledger above
  names the plan items that are not done and why.
- **Maintainer decisions (2026-10-29).** The 2.0 macOS bundle ships ad-hoc signed: no
  notarization is attempted and no Developer ID secrets are needed (ADR 0094 is not adopted
  for 2.0). No soak runs are needed, so the 72-hour soak is dropped. Both decisions are
  recorded here as `Not needed` rather than as blocked work.
