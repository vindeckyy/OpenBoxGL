# Trademark and branding policy

OpenBox Game Launcher is an independent open-source Linux game library manager and launcher.

## Project identity

Use the full name **OpenBox Game Launcher** in public listings, package descriptions, screenshots, and release announcements when space allows. The project is unrelated to [Openbox](https://openbox.org/), the Linux window manager, and is not affiliated with its maintainers.

The project is also independent from LaunchBox, Big Box, Unbroken Software, LLC, and every other third-party product named in the repository. Do not describe OpenBox Game Launcher as official, endorsed, sponsored, or produced by another project or company.

The `io.openbox.GameLauncher` application ID and `openbox://` URI scheme are technical identifiers. They do not imply affiliation with the Openbox window manager.

## Third-party names and logos

Third-party names, logos, and marks belong to their respective owners. OpenBox uses product names in documentation and interface text only when needed to describe:

- compatibility or interoperability;
- supported import, launch, or metadata workflows; or
- a factual feature comparison.

Do not copy third-party logos, artwork, screenshots, or other branded assets into the repository or release artifacts without a documented license or permission. New contributions that include third-party assets must state the source and applicable license.

## Formal notices

Do not post private contact details or formal legal notices in public issues. Use GitHub's [copyright claims form](https://github.com/contact/dmca) for copyright complaints and the [GitHub Trademark Policy](https://docs.github.com/en/site-policy/content-removal-policies/github-trademark-policy) for trademark complaints.

This policy is a project guideline, not legal advice. It does not determine whether a particular use is lawful in any jurisdiction.
